# 排错速查

| 现象 | 处理 |
|---|---|
| 页面跳登录 | 请用户在当前浏览器登录抖音后重试；不要猜 Cookie |
| 403 / 风控 | 只使用已登录浏览器和浏览器自己的请求；不要改用 yt-dlp、curl、裸 HTTP |
| 没有 `media-audio` | 刷新页面，重新记录加载时间，确认不是只筛了 `media-video` |
| 音频时长对不上 | 可能抓到上一条视频的缓存音频；按当前 video_id、加载时间、路径去重和时长重新核对 |
| 转写服务无法解析 | 原始 m4a 未转码，或 MP3 没有上传为可访问 URL；转成 16kHz 单声道 MP3 后重试 |
| 只有摘要没有逐字稿 | 继续读取转写文档正文或逐字稿节点；不能用摘要冒充逐字稿 |
| 元数据数字异常 | 不要读整页文本；只从当前视频的 `data-e2e` 字段读取 |
| 批量结果错配 | 每条音频抓取后立即记录 video_id 和 duration_sec，输入条数必须等于成功数加失败数 |
